DELICAT RECHARGE MODERN WALLET v5.0.7

Fixes and improvements:
- Keeps the fixed “Envoyer de l’argent” dropdown behavior.
- Adds a new QR code option for receiving money.
- QR modal shows the client’s Delicat code and a copy button.
- “À un autre client Delicat” opens the old transfer dropdown/form correctly.
- Recharge button still scrolls down to the recharge section.
- Icons are smaller and more mobile friendly.
- Added better glass dropdown styling and mobile-safe positioning.

Safe update:
- Admin support untouched.
- Licensing system untouched.
- Recharge logic untouched.
- Wallet transfer logic untouched.
- Existing shortcodes kept:
  [delicat_recharge]
  [delicat_wallet_balance]
  [delicat_balance_card]

After installing:
1. Upload and activate the plugin ZIP.
2. Clear LiteSpeed/Cloudflare/browser cache.
3. Open the wallet page on mobile.
4. Tap “Envoyer de l’argent”.
5. Choose “À un autre client Delicat” or “Recevoir par QR code”.
