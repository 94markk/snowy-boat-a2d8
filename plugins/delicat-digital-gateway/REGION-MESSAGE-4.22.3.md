# Account server message

On a confirmed server mismatch with a known account server, clients now see its name and a direction to purchase in the matching Free Fire section.

Example for an account on the Americas server:
Désolé, ce compte est enregistré sur un autre serveur : Amérique / LATAM (NA). Veuillez effectuer votre transaction dans la rubrique Free Fire du serveur Amérique / LATAM (NA).

The supplier must return a recognized actual account server. Unknown or conflicting server data is not invented. An explicit server rejection without an account server name asks the client to check the server in-game and transact in the corresponding section.

Install both ZIP updates over the existing plugins, then clear the site cache and reload the product page. This release changes the server notice; it does not resolve the separate supplier nickname discrepancy or add a Garena integration.

Validated with mocked API, app and cart message tests and existing regression suites. No production deployment or live supplier validation performed.
